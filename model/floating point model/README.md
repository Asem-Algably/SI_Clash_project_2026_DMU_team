# Si-CLASH Carrier & Timing Synchronization Unit — MATLAB Floating-Point Golden Model

## 1. Executive Overview & Architecture
This repository contains the complete, modular **floating-point MATLAB Golden Model** and verification environment for the **Real-Time All-Digital Carrier and Timing Synchronization Subsystem** (QPSK and 16-QAM at 4 samples per symbol, 31.25 MSps nominal symbol rate at a 125 MHz system clock).

### Stated Assumptions for Open Questions (Q-a, Q-b, Q-c)
Until official clarification from the organisers, the model supports both answers to each open question via single switches in `config/get_default_config.m`:
- **Q-a (`cfg.snr_def = 'esn0' | 'sample'`)**: Controls whether `cfg.snr_dB` specifies symbol-rate $E_s/N_0$ after matched filtering (`'esn0'`, default) or per-sample SNR at the $4\times$ oversampled rate (`'sample'`, where $E_s/N_0 = \text{SNR} + 10\log_{10}(4)$).
- **Q-b (`cfg.evm_norm_mode = 'rms' | 'peak'`)**: Both RMS-referenced EVM ($\sqrt{\mathbb{E}|e|^2}/\sqrt{\mathbb{E}|s|^2}$) and Peak-referenced EVM ($\sqrt{\mathbb{E}|e|^2}/\max|s|$) are computed from the actual transmitted payload symbols and printed side-by-side along with the measured noise-floor EVM and excess EVM.
- **Q-c (`cfg.norm_mode = 'peak' | 'rms'` & `cfg.input_headroom = 0.22`)**: Assumes a fixed nominal input level with no AGC, scaled by `cfg.input_headroom = 0.22` prior to signed 12-bit `Q1.11` quantisation (`0` clipped samples) and `cfg.output_scale = 0.50` prior to signed 16-bit `Q1.15` output quantisation.

## 3. Register Saturation vs. Wrapping Policy (Part 4c)

- **Wrapping by Design (Modulo Arithmetic):**
  - `eta` (`modulo1_controller.m`): Decrementing modulo-1 timing phase counter in $[0, 1)$; wraps by $+1.0$ on every symbol `strobe`.
  - `nco_phase` (`nco_32bit.m`): Carrier phase accumulator; wraps modulo-$2\pi$ into $(-\pi, \pi]$ around the unit circle.
- **Saturating (Clamped with Anti-Windup / Hardware Safety Limits):**
  - `in_sample_i/q`: Signed 12-bit `Q1.11` input (`[-1.0, 1.0 - 2^-11]`, `q11_clip_count == 0`).
  - `buf4`, `farrow_interpolator`, `gardner_ted`, `derotator`, `costas_phase_detector`: Linear datapath nodes saturate on overflow to prevent sign inversion.
  - `int_state` & `v_pi` (STR PI loop filter): Clamped to `[-cfg.str.max_v_pi, +cfg.str.max_v_pi]` (`+-0.035`, $W \in [0.215, 0.285]$) with conditional anti-windup (`str_sat_count == 0`).
  - `costas_int` & `v_pi` (Costas PI loop filter): Clamped to `[-cfg.costas.max_v_pi, +cfg.costas.max_v_pi]` (`+-0.12`) with conditional anti-windup (`costas_sat_count == 0`).
  - `bucket` & `quad_counts[1..4]`: Unsigned saturating counters (`0 .. confirm_cnt`).
  - `out_sym_i/q`: Signed 16-bit `Q1.15` output (`[-1.0, 1.0 - 2^-15]`, `q15_clip_count == 0`).
