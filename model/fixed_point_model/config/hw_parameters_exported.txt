  System Clock (F_clk)      : 125.00 MHz [R.101]
  Samples Per Symbol (sps)  : 4 samples/symbol [R.102]
  Symbol Rate (R_sym)       : 31.25 MSps [R.103]
  Default Modulation        : 16-QAM (mod_type = 1) [R.107]
  Front-End Scale (/2)      : 0.5000 (maps [-2, +2) to [-1, 1 - 2^-11) Q1.11 at input)
  Preamble Schedule         : A1 (STR) = 70, A2 (CFO) = 40, B (Costas) = 30, C (Quad) = 50 (Total = 190 syms)

------------------------------------------------------------------------------------------------------------------
  1. VALID SIGNAL, WATCHDOG & FLUSH TIMING SPECIFICATION
------------------------------------------------------------------------------------------------------------------
  Hardware Valid Enable     : 1 (STR clock-enabled via ce_str = s_axis_valid_i | flush_active)
  Idle Watchdog Timeout     : 14 consecutive invalid clocks (triggers FLUSH state)
  Flush Fill Mode           : repeat (samples fed to STR during FLUSH)
  Flush Safety Margin       : 4 clock cycles
  Derived Flush Duration (F): 15 clock cycles
    Formula : F = sps (4) + lat.str (4) + lat.derot (2) + lat.wrap_out (1) + margin (4) = 15 clocks
  Downstream Pipeline Action: Free-running on wall clock; soft-reset clears all modules at end of FLUSH (F clocks)
